Rôle d’un IDS

Un système de détection d’intrusion observe un réseau (NIDS) ou une machine (HIDS) et alerte lorsqu’il repère un comportement malveillant. Un IPS va plus loin en bloquant le trafic.

Ici, l’analyse porte sur des statistiques de flux (durée, volumes, paquets, protocole, service), pas sur le contenu des paquets.

Faux positifs et faux négatifs

Un faux négatif est une attaque manquée (rappel). Un faux positif est une fausse alerte (précision).

En environnement SCADA, une attaque manquée peut toucher la sécurité d’un procédé : le rappel est prioritaire.

Hyperparamètres et données
Lecture critique
  • Séparation apprentissage/test aléatoire dans un même jeu : les flux d’une même attaque se ressemblent, le test est donc optimiste. La validation indépendante est plus représentative.
  • Un modèle linéaire capture mal les attaques proches du trafic normal : voir les familles à faible rappel.
  • Les scores décrivent le passé : une évolution du trafic dégrade la détection.

ÉTAPE 3

Déploiement sûr

ÉTAPE 4

Intégration continue

ÉTAPE 5

Service d’inférence
